## What's here

- **Foundations**: color tokens (including the brand accent pair), the type
  scale, radii and the effects used across the site: gradient text, the
  spotlight border, the page backdrop and frosted surfaces
- **Components**: every component in `components/ui` (the **Radix · Nova**
  style of shadcn/ui), with interactive controls and generated docs
- **Patterns**: site-level building blocks made from those components, such as
  project cards and section headings

Use the **paintbrush** button in the toolbar to switch between light and dark
themes. The **Accessibility** panel runs axe checks against each story.

## Stack

- React 19 and Next.js 16
- Radix UI primitives for accessible behavior
- Tailwind CSS v4 with CSS-variable theming in OKLCH
- `class-variance-authority` for variants
- Lucide icons and the Geist typeface

## Adding a component

```bash
npx shadcn@latest add tabs
```

Then add a `tabs.stories.tsx` file next to it in `components/ui`.
